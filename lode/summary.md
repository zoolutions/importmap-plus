# importmap-plus

A drop-in replacement for rails/importmap-rails, published as the `importmap-plus` gem. Same `Importmap::` constants, engine, helpers and pin DSL, so an app switches by changing one Gemfile line and can switch back: every `config/importmap.rb` this gem writes still parses under importmap-rails, because everything the fork adds rides in a comment (`# @version (provider, minified, locked, vendored, remote: reason)`). The additions all live on the vendoring side of the CLI (`bin/importmap pin --minify`, `--from esm.run`, version locks, `update <package>`, single-file inspection before vendoring, a provider fallback chain); the request path (engine → `Map` → helpers) is upstream's and does no network I/O. The fork keeps merging upstream releases, so upstream-owned files are edited additively and new behaviour goes in fork-only collaborators (`minifier.rb`, `http_retries.rb`, `module_inspector.rb`, `provider_chain.rb`). Three invariants govern every change: the importmap-rails surface never breaks, no runtime dependency is added, and a pin's provenance and options survive every rewrite.
